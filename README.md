# 将棋大乱闘

ルールは `GAME_SPEC.md`、カードは `cards_v0.1.json`。

## 遊び方

- **公開サイト：https://helloeveryonekusoo.github.io/shogi-dairantou/**
  - 右上の「ログイン／新規登録」でアカウントを作る（メール＋パスワード、無料）
  - 「マイデッキ」でデッキを作成・編集・保存・複製・削除
  - 「オンライン対戦」で部屋を作ると6文字の部屋コードが出る → 相手がそのコードで参加すると対局開始（先手・後手はランダム）
- 「2人で対戦（同じ端末）」「CPUと対戦」はログインなしで遊べます。
- 駒をクリック → 動ける先が青い点（取れる駒は赤、入れ替えは水色）で出ます。持ち駒もクリックして打てます。
- 能力の対象を選ぶときは、候補の駒が紫に光るのでクリックします。
- 駒にカーソルを合わせると右にカードの詳細。「実装上の解釈を見る」で、能力をどう解釈しているかが見られます。

## 公開のしくみ

- `main` ブランチに push すると、GitHub Actions（`.github/workflows/pages.yml`）がテスト → ビルド → GitHub Pages への公開を自動で行います。
- アカウントとデータは Firebase（プロジェクト `onlineduel-866b6`、無料の Spark プラン）。
  - データベースのルールは `firestore.rules`。変えたら `firebase deploy --only firestore:rules`
  - デッキは `users/{uid}/decks`、対戦の部屋は `rooms/{部屋コード}` に保存
- オンライン対戦は「両者の編成」と「指した手の列」だけを保存し、両方の端末が同じ手を適用して局面をそろえます（エンジンは同じ手から必ず同じ局面になる）。

## カードやルールを変えたあと

カードの数値（HP・ATK・コスト・能力テキストの数字）を `cards_v0.1.json` で変えたら、push すれば公開サイトに反映されます。
手元で確認するときは `npm run dev`（ブラウザで http://localhost:5173 を開く）。テストは `npm test`。
`npm run build` で、ダブルクリックで遊べる `将棋大乱闘.html` も作られます。

## フォルダの中身

| 場所 | 中身 |
| --- | --- |
| `src/engine/` | ルールエンジン（画面に依存しない純粋なロジック）。`game.ts` が手の適用と能力の発動 |
| `src/engine/config.ts` | 未決定ルールの設定値（画面の「ルール設定」からも切り替え可。オンライン対戦は初期値で固定） |
| `src/data/abilities.ts` | 能力テキスト → 構造化データ（トリガー・条件・対象・効果）。数値はテキストから読む |
| `src/data/movements.ts` | 「将棋どおり」以外の動きの定義 |
| `src/ai/cpu.ts` | かんたんなCPU |
| `src/ui/` | 画面（React） |
| `src/online/` | Firebase（アカウント・マイデッキ・オンライン対戦の部屋） |
| `src/ui/effects/registry.ts` | **エフェクト（演出）の登録場所** |
| `tests/` | エンジンのテスト |
| `docs/ABILITY_REVIEW.md` | 能力テキストと実装上の解釈を並べた表（`npm run review` で再生成） |
| `docs/要確認リスト.md` | 仮の解釈で実装したところの一覧 |

## エフェクト（演出）について

エンジンは1手ごとに「起きたこと」（撃破・ダメージ・回復・覚醒・行動不能…）をイベントの列として返し、
画面はそれを順番に再生して演出を出しています。演出の中身は `src/ui/effects/registry.ts` にまとまっていて、

- 全体の演出 … `DEFAULT_EFFECTS`（イベントの種類ごと）
- カード専用の演出 … `CARD_EFFECTS['rook_01']` のようにカードIDごとに上書き

で差し替えられるようにしてあります。いまは仮の演出（ダメージ数字・能力発動の帯・マスの光・盤の揺れ）です。
