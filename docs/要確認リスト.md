**2026-11-14 に確認済み**：✅ は決定済み（理由つきで変えた項目は「→」で記載）。無印は未確認で仮のまま。

仕様書・カードテキストだけでは決めきれなかった点です。いまは下の「仮の解釈」で動いています。

## A. ルール全体

| # | 項目 | 仮の解釈 |
| --- | --- | --- |
| A1 | ⚙「隣」の範囲 | ✅ → **前後左右の4マス**（斜めは含まない）。エリザベス1世の「周り8マス」は別扱い |
| A2 | ⚙ 撃破ダメージ軽減が複数かかったとき | ✅ → **かけ算**（−20%と−30%なら0.8×0.7＝−44%） |
| A3 | 撃破ダメージの増減の順番 | ATK（加算→％補正）×（1＋撃破ダメージ増加％）×（1−軽減％）、最後に四捨五入 |
| A4 | 能力の「味方」に自分自身を含むか | ✅ → **含む**：撃破ダメージ軽減の能力は、その駒自身が取られたときにも効く（マザー・テレサが取られたら−20%）。※取られたときに発動する能力（ワシントン・マンデラなど）は今まで通り自分自身では発動しない |
| A5 | 能力の対象を「1体」選ぶとき | ✅ → **指した人が選ぶ**（候補が2体以上のとき、盤上か持ち駒をクリック）。CPUは自動（ATKが一番高い敵／コストが一番高い持ち駒） |
| A6 | 同じ手で起きる処理の順番 | 撃破ダメージ → 取った駒の能力 → リーダー（味方が撃破したとき）→ 取られた駒の能力（【罠】など）→ 周りの駒の能力 → 動いたときの能力（跳び越え等）→ 成り・覚醒 → 金の敵陣効果 → ヒット＆アウェイ → 王手の判定（クレオパトラ） |
| A7 | 取られた駒の能力が発動できるか | 「取られる直前」の状態で判定（直前に封印・縦の利きの中にいたら発動しない） |
| A8 | ⚙ 封印中・ハンニバルの縦の利きの中で止まる能力 | ✅（こだわりなし→今のまま）能力も【覚醒】【敵陣】【リーダー】もすべて止まる |
| A9 | 行動不能・封印・ATK増減の「N手番」の数え方 | 効果を受けた駒の持ち主の手番の終わりに1減る。持ち主の手番中にかかった場合（【罠】など）は、その手番は数えない |
| A10 | 同じ駒に行動不能・封印が重なったとき | ✅ 長い方が残る（重ねて延びはしない） |
| A11 | ⚙ 毒の重ねがけ | 別々に効く（上書きにも切り替え可） |
| A12 | リーダー倍率をかける数値 | リーダースキルの数値（％も、HP400回復のような量も）にかける |
| A13 | 王手の判定 | 相手の駒の動きで王のマスに行けるか（行動不能の駒も王手をかけていると見なす） |
| A14 | ⚙ 金を敵陣に「打った」とき | 敵陣効果は発動しない（敵陣に置かれているだけ）。押し出しで敵陣に入っても発動しない |
| A15 | ⚙ 同じカードを2枚以上編成 | できない（1枚まで） |
| A16 | 動かせる駒が1つもないとき | パス（相手の手番になる） |
| A17 | 千日手の「同じ局面」 | 盤上の駒（カード・持ち主・成り）＋両者の持ち駒＋手番が同じ。HP・状態異常は見ない |

## B. カードごとの解釈

| # | カード | 仮の解釈 |

| B1 | エリザベス1世（入れ替え） | 「隣の味方」と入れ替え。行動不能の味方とは入れ替えない。入れ替えで成ることはない |
| B2 | クレオパトラ | 王手をかけた駒が2枚以上なら全部を行動不能に（1回の発動として数える） |
| B3 | ✅ ハンニバル | 「縦の利き」＝上下それぞれ最初にぶつかる駒のマス。そこにいる敵（最大2体）の能力が止まる。縦に動いてハンニバルが駒を取ると、取られた駒は直前まで利きの中にいたので【罠】は発動しない |
| B4 | ✅ ドレーク・クック（前方で一番近い敵） | 同じ筋の前方にいる一番近い敵（斜め前などは含まない） |
| B5 | ✅ ダ・ヴィンチ（通り抜けた斜線上の敵） | 将棋の動きでは敵の上を通り抜けられないので、「動いた斜めの線を盤の端から端まで伸ばした線の上にいる敵すべて」と解釈 |
| B6 | ✅ ロビン・フッド／ウィリアム・テル（貫通） | 斜め（縦）に動いて取ったときだけ。動いた向きのさらに先へ、間の駒を無視して最初の敵1体にダメージ |
| B7 | ✅ フーディーニ／ジェロニモ（跳び越えた敵） | 跳び越えたマス＝跳ぶ向きの途中の2マス（前に桂跳びなら「1つ前」と「1つ前の斜め」）。駒を取らずに跳んでも発動 |
| B8 | ✅ ネルソン（同じ筋の敵1体） | 同じ筋にいる敵から指した人が選ぶ（前後どちらでも） |
| B9 | ピカソ（押し出し） | 隣の敵から指した人が選ぶ（押し出せない敵を選ぶと、押し出しは起きず覚醒なら行動不能だけかかる） |
| B10 | ダルタニャン（ヒット＆アウェイ） | 撃破した手で、着地したマスから斜め後ろの空きマスへ下がるかを選べる。成り・覚醒の後に下がる |
| B11 | ガンディー（取った駒のATK−30%） | 【罠】の印はないが、【罠】と同じタイミング（取られたとき）で発動 |
| B12 | ネルソン・マンデラ（味方の歩） | 成っている歩（と金）が取られても発動 |
| B13 | ✅ ファーブル（次に受ける撃破ダメージ） | この駒に限らず、自分の駒が次に取られたときの撃破ダメージ−30%（1回で消える） |
| B14 | スパルタクス（ATK+500） | その撃破の後から上がる。取られたら元に戻る |
| B15 | コロンブス（敵陣にいる間ATK+30%） | 撃破したマスが敵陣ならその撃破から+30% |
| B16 | メディチ（覚醒で+600に） | 覚醒した後は+300ではなく+600（足して+900ではない） |
| B17 | マキャヴェッリ（次に打つときの自傷+500） | 相手が打つ前にもう一度発動したら+1000に重なる |
| B18 | ジャンヌ・ダルク（入れ替え） | 王の「隣」にいるとき、移動の代わりに王と入れ替え |
| B19 | クレオパトラ（自傷+10%） | メディチなどの加算を足した後の合計に+10% |
| B20 | ダ・ヴィンチ（持ち駒を除外） | 相手の持ち駒から指した人が選ぶ。持ち駒がなければ何も起きない |
