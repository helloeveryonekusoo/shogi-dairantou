# 能力の解釈レビュー表

`cards_v0.1.json` の能力テキストを、ゲームエンジンでどう解釈して実装したかの一覧です。
「解釈」の列は `src/data/abilities.ts` の構造化データから自動で作っています（`npm run review` で再生成）。
数値はカードのテキストから読んでいるので、JSON の数値を変えるとここにも反映されます。
